# 2G2BT · Light / Dark palette

Light is the default. Purple and blue are reserved for active navigation, primary actions and focus. Each color below has a semantic role so the interface can switch themes without changing page layout.

| Role | Light | Dark | Use |
| --- | --- | --- | --- |
| Canvas | `#F7F8FC` | `#0A0B10` | Main page background |
| Surface | `#FFFFFF` | `#15161C` | Cards, inputs, menus |
| Soft surface | `#EEF0F7` | `#20212A` | Hover, quiet sections |
| Primary text | `#171923` | `#F6F6FA` | Headings and body |
| Secondary text | `#586174` | `#A5A9BA` | Captions and metadata |
| Border | `#DBDFEA` | `#313341` | Dividers and outlines |
| Accent | `#5B55DF` | `#B4A5FF` | Links, focus, selected controls |
| Accent soft | `#ECEBFF` | `#29243E` | Tinted cards and tags |
| Sidebar | `#FFFFFF` | `#0B0B10` | Investor navigation |
| Success | `#167A5B` | `#7BE0BD` | Positive status |
| Caution | `#A3620A` | `#F4C46C` | Warnings |
| Error | `#C13C59` | `#FDA4AF` | Errors |

Active navigation uses `#6657EB → #4F6FEB` in both modes with white text. The original 2GOOD2BETRUE mark changes from cream on dark to charcoal on light via a CSS filter; the SVG source remains intact.
